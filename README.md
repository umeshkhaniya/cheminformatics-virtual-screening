# 🔬 Ligand-Based Cheminformatics for BCR-ABL Kinase Inhibitors

This repository provides a ligand-based cheminformatics pipeline focused on **BCR-ABL kinase**, a key target in **chronic myeloid leukemia (CML)**. 
BCR-ABL is a fusion protein resulting from a reciprocal translocation between chromosomes 9 and 22, known as the Philadelphia chromosome (Ph). This fusion combines the breakpoint cluster region (BCR) gene with the Abelson murine leukemia viral oncogene homolog 1 (ABL1) gene, producing a constitutively active tyrosine kinase.

🔹 Clinical Significance
- The BCR-ABL fusion protein plays a central role in the pathogenesis of chronic myeloid leukemia (CML) and some types of acute lymphoblastic leukemia (ALL).

- Its abnormal kinase activity drives uncontrolled cell proliferation and resistance to apoptosis.

- It is a validated drug target, with several FDA-approved inhibitors developed against it, including:

- Imatinib (Gleevec) — the first BCR-ABL inhibitor, revolutionized CML treatment

- Dasatinib, Nilotinib, Bosutinib — second-generation inhibitors

- Ponatinib — active against the T315I mutatio


Using publicly available bioactivity data from [ChEMBL](https://www.ebi.ac.uk/chembl/), this project demonstrates how to perform:

- Virtual screening  
- Molecular descriptor calculation  
- Compound clustering  
- Machine learning-based QSAR modeling  

The pipeline uses Python tools including **RDKit**, **scikit-learn**, and **pandas**, and is intended as a reproducible, beginner-friendly resource for drug discovery and cheminformatics.
