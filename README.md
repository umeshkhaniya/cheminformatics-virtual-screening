# 🔬 Ligand-Based Cheminformatics for BCR-ABL Kinase Inhibitors

This repository provides a ligand-based cheminformatics pipeline focused on **BCR-ABL kinase**, a key target in **chronic myeloid leukemia (CML)**. Using publicly available bioactivity data from [ChEMBL](https://www.ebi.ac.uk/chembl/), this project demonstrates how to perform:

- Virtual screening  
- Molecular descriptor calculation  
- Compound clustering  
- Machine learning-based QSAR modeling  

The pipeline uses Python tools including **RDKit**, **scikit-learn**, and **pandas**, and is intended as a reproducible, beginner-friendly resource for drug discovery and cheminformatics.
